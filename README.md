# Archie Portfolio

A minimal technical portfolio built with React + Vite.

## Run locally

```bash
npm install
npm run dev
```

## First things to edit

Open `src/main.jsx` and replace:

- GitHub URL
- LinkedIn URL
- email address
- project GitHub links
- project descriptions / metrics

Styling lives in `src/styles.css`.

## Deploy

Push this folder to GitHub and import the repo into Vercel. Vercel will detect Vite automatically.
